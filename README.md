**Overview**

This project builds an end-to-end Machine Learning pipeline to predict used BMW car prices using vehicle attributes such as mileage, engine power, fuel type, and age. Multiple regression models were evaluated, with Gradient Boosting achieving the best performance (R² = 0.81).

**Dataset Used**

https://www.kaggle.com/datasets/danielkyrka/bmw-pricing-challenge

**Key Features**

Data cleaning and preprocessing
Feature engineering (car age, mileage/year, power/year)
Outlier removal and log transformation
Decision Tree, Random Forest, and Gradient Boosting models
Hyperparameter tuning using GridSearchCV
Performance evaluation using MAE, RMSE, and R
